# Conversor de Divisas BCRA (Argentina)
Este es un conversor de moneda sencillo y elegante que utiliza la API de **DolarApi.com** para obtener las cotizaciones oficiales del Banco Central de la República Argentina (BCRA) en tiempo real.
## 🚀 Características
 * Cotizaciones actualizadas de: **Dólar, Euro, Real y Peso Uruguayo**.
 * Cálculo automático al ingresar montos.
 * Interfaz moderna y adaptable a dispositivos móviles (Responsive Design).
 * Desarrollado con HTML5, Tailwind CSS y JavaScript vainilla.
## 🛠️ Cómo subirlo a GitHub
 1. Crea un nuevo repositorio en GitHub (ejemplo: conversor-bcra).
 2. Sube el archivo index.html de este proyecto.
 3. Ve a **Settings** (Configuración) > **Pages**.
 4. En "Build and deployment", selecciona la rama main y la carpeta / (root).
 5. Dale a **Save** y en unos minutos tendrás tu link tipo https://tu-usuario.github.io/conversor-bcra/.
